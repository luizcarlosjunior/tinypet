# tinyPet Blog — contract (v1)

Base `/api/v1`, envelope `{ ok: true, data, meta? }` / `{ ok: false, error: { code, message, details } }` (see `docs/api-contract.md`).
Schema: `BlogPost` has denormalized `heartsCount`, `commentsCount` and a `commentsEnabled` flag. `BlogCategory` (tree via `parentId`), `BlogPost`, `BlogPostCategory`, `BlogSlugRedirect`, `BlogMedia`, `BlogPostViewLog`, `BlogPostDailyStat`, `BlogComment`, `BlogPostHeart`, `BlogCommentHeart`, `BlogCommentReport` in `packages/db/prisma/schema.prisma`. Role `EDITOR` (blog team) in `UserRole`.

Reference implementation we mirror (read-only): `/Volumes/512gb/APPs/CTEC/blog` — image upload (`src/components/admin/ImageUploadWithCrop.tsx`, `MediaUploadDialog.tsx`, `src/app/api/upload-image/route.ts`), TipTap editor (`src/components/admin/editor/NotionEditor.tsx`), stats (`src/app/admin/noticias/estatisticas/page.tsx`, `src/lib/jobs/process-view-jobs.ts`). It runs Next 15 — we are on Next 14 (route `params` is a plain object).

## Roles
- `ADMIN` and `EDITOR` manage the blog (`requireBlogEditor(req)`). `EDITOR` can access only `/admin/blog/**` in the admin UI and only `/api/v1/admin/blog/**`.
- Readers: anyone can read published posts. Commenting and hearts require a logged-in account (any role).

## Content & media rules
- Post `content` = HTML from TipTap, sanitized server-side on save (isomorphic-dompurify): allow headings, paragraphs, lists, blockquote, code/pre, hr, br, strong/em/u/s/sub/sup/mark, a (href http/https/mailto only, add `rel="noopener noreferrer nofollow"` + `target="_blank"` for external), img (src must be our media host — `BlogMedia.url` prefix / S3 public base — attributes `src alt width data-align style` where style limited to width/float/margin), tables, iframes only for `youtube-nocookie.com`/`youtube.com/embed`. Strip everything else (scripts, on* handlers, forms, svg).
- `readingMinutes` = ceil(words / 200). `summary` ≤ 300 chars. `seoTitle` ≤ 60, `seoDescription` ≤ 180. Slug: slugify(title), unique; changing a published post's slug creates a `BlogSlugRedirect`.
- Status `DRAFT | SCHEDULED | PUBLISHED | ARCHIVED`. SCHEDULED requires future `publishDate`; the job publishes when due. PUBLISHED without `publishDate` sets now.
- Images (same as the reference blog): processed in the browser (canvas) — longest side ≤ 1920 px, WebP quality 85 (slider 1–100, "otimizar" toggle); covers cropped with `react-image-crop`: `coverImageRect` 16:9 → 1920×1080, `coverImageSquare` 1:1 → 1080×1080, `coverOgImage` 1200×630 sent as PNG and optimized server-side with sharp. Upload is multipart to our API (server `PutObject` to S3 via `storeBytes` in `apps/web/src/server/media.ts`; key `blog/images/<uuid>.<ext>`). Accepted: jpeg, png, webp, gif — **no SVG**. Max 10 MB. Magic-byte check (`bytesMatchMime`). Metadata (width/height via sharp) saved in `BlogMedia`.

## Admin API (`requireBlogEditor`)
- Categories: `GET /admin/blog/categories` → tree `[{ id, name, slug, description, sortOrder, active, postCount, children: [...] }]` · `POST` `{ name, slug?, description?, parentId?, sortOrder?, active? }` (max depth 2: a subcategory cannot have children) · `PATCH /admin/blog/categories/:id` · `DELETE /admin/blog/categories/:id` (409 if it has children or posts, unless `?force=1` which unlinks posts).
- Posts: `GET /admin/blog/posts?q&status&categoryId&authorId&page&pageSize` (paginated, `meta`) → `[{ id, slug, title, status, publishDate, author{id,name}, categories[{id,name,parentId}], views, heartsCount, commentsCount, coverImageRect, updatedAt }]` · `POST /admin/blog/posts` · `GET|PATCH|DELETE /admin/blog/posts/:id` (DELETE = soft) · body fields: `title, slug?, summary?, content, status, publishDate?, categoryIds[], tags? (string[] → stored comma-separated), coverImageRect?, coverImageSquare?, coverOgImage?, coverAlt?, seoTitle?, seoDescription?, featured?, commentsEnabled?`.
- Media: `GET /admin/blog/media?q&type&inUse&trash&page` · `POST /admin/blog/media` multipart `file` + optional `optimize=true&format=webp|png&quality=1..100&alt` → `{ id, url, width, height, size, mimeType, originalFilename, alt }` · `PATCH /admin/blog/media/:id { alt }` · `DELETE /admin/blog/media/:id` (soft; 409 when in use unless `?force=1`) · `POST /admin/blog/media/:id/restore` · `GET /admin/blog/media/:id/usage` → `[{ postId, title, field: "content"|"coverImageRect"|"coverImageSquare"|"coverOgImage" }]` · `POST /admin/blog/media/estimate` multipart `file` → `{ pngSize, webpSize, width, height }` (no save).
- Stats: `GET /admin/blog/stats?period=7d|30d|90d|12m|custom&from&to&postId?&categoryId?` → `{ totals: { views, visitors, hearts, comments, published }, series: [{ bucket: "YYYY-MM-DD"|"YYYY-MM", views, visitors, published }], topPosts: [{ id, title, slug, views, hearts, comments }], byCategory: [{ id, name, views }], referrers: [{ host, views }], devices: [{ device, views }] }` (from `BlogPostDailyStat` + unprocessed logs for today; referrers/devices from logs ≤ 90 days).
- Comments moderation: `GET /admin/blog/comments?status&postId&reported=1&page` → `[{ id, body, status, createdAt, post{id,title,slug}, user{id,name,username,email}, heartsCount, reportsOpen, parentId }]` · `POST /admin/blog/comments/:id { action: "HIDE"|"RESTORE"|"DELETE"|"DISMISS_REPORTS" }`.

## Public API
- `GET /blog/categories` → active tree.
- `GET /blog/posts?category=<slug>&tag=<tag>&q&page&pageSize` → published (status PUBLISHED, `publishDate ≤ now`, not deleted); a category slug includes its subcategories. Items: `{ id, slug, title, summary, coverImageRect, coverImageSquare, coverAlt, publishDate, readingMinutes, categories[{name,slug}], author{name}, heartsCount, commentsCount }`.
- `GET /blog/posts/:slug` → full post + `viewerHearted` (when logged in); old slug → `{ redirectTo: "<new-slug>" }` with 301 in pages.
- `POST /blog/posts/:id/view { screenWidth, screenHeight, referrer? }` → 204 (`referrer` = the page's `document.referrer`; stored as host only). Same-origin check for browsers (Origin, or Referer without Origin); the native app sends no Origin and is accepted only with a **valid** mobile JWT (`Authorization: Bearer`, fully verified) — its logs get `device: "app"`; a foreign Origin is always 403. `?preview=1` → ignored. Bot UA filter, rate limit 60/min per visitor. `visitorHash = sha256(ip + ua + YYYY-MM-DD + BLOG_VIEW_SALT||NEXTAUTH_SECRET)` — never store raw IP.
- Hearts (auth): `POST /blog/posts/:id/heart` and `POST /blog/comments/:id/heart` → toggle → `{ hearted, heartsCount }` (rate limit 60/min per user; counters updated atomically).
- Comments: `GET /blog/posts/:id/comments?cursor&limit=20` → `{ items: [{ id, body, createdAt, editedAt, user{id,name,username,avatarUrl}, heartsCount, viewerHearted, canEdit, canDelete, replies: [same, no nested replies] }], nextCursor }` (VISIBLE only; newest first for top level, oldest first for replies) · `POST /blog/posts/:id/comments { body, parentId? }` (auth; body 2–2000 chars, trimmed, plain text — rendered escaped with line breaks and autolinked http(s) URLs with `rel="nofollow ugc noopener"`; max 2 links; rate limit 5/min and 50/day per user; post must be published with `commentsEnabled`; `parentId` must be a top-level comment of the same post) · `PATCH /blog/comments/:id { body }` (author; sets `editedAt`) · `DELETE /blog/comments/:id` (author or blog editor; soft) · `POST /blog/comments/:id/report { reason }` (auth, once per user). Reply → `notify()` the parent comment's author (`type: "blog_comment_reply"`, `data.route: "/blog/<slug>"`). Post `commentsCount` counts VISIBLE, non-deleted comments (keep in sync on create/delete/moderation).

## Jobs (cron secret, GET+POST via `cronRoute`)
- `/jobs/blog-views` (every 10 min): process unprocessed `BlogPostViewLog` → `BlogPost.views`, `viewsLast7Days`, `viewsThisMonth`, upsert `BlogPostDailyStat` (views, distinct visitorHash per day, SP timezone), mark processed; prune processed logs older than 90 days.
- `/jobs/blog-publish-scheduled` (every 5 min): SCHEDULED with `publishDate ≤ now` → PUBLISHED.

## Web pages
- Public (`apps/web/app/(public)/blog/**`): `/blog` (featured + latest, category chips), `/blog/[slug]` (SSR, SEO metadata + OG image + JSON-LD `BlogPosting`, view beacon, heart button, comments), `/blog/categoria/[slug]`, `/blog/tag/[tag]`, `/blog/rss.xml`; posts in `sitemap`.
- Admin (`apps/web/app/admin/blog/**`): Posts list + editor, Categorias, Mídia, Estatísticas (recharts), Comentários (moderation).

## Implementation notes (v1)
- Code: `apps/web/src/server/blog/**` (`auth.ts` `requireBlogEditor`, `sanitize.ts`, `posts.ts`, `categories.ts`, `comments.ts`, `hearts.ts`, `media.ts`, `stats.ts`, `views.ts`, `jobs.ts`; pure helpers `utils.ts`, `text.ts`, `period.ts`, `visitor.ts`), routes under `app/api/v1/blog/**`, `app/api/v1/admin/blog/**`, `app/api/v1/jobs/blog-*`.
- Route segment: Next requires one dynamic name per level, so `GET /blog/posts/:id` accepts a **slug or an id**. `?preview=1` (blog editors only) returns any non-deleted post, and the page `/blog/<slug>?preview=1` renders it (noindex, no view beacon).
- Public list extras: `featured=1`, `exclude=<postId>`; `meta.category` when filtering by category. Items include `featured`. `summary` falls back to an excerpt of the content.
- Full post extras: `status, updatedAt, tags[], categories[{id,name,slug,parentId}], author{id,name,avatarUrl}, commentsEnabled, views`.
- Comments list also returns `commentsEnabled`; items include `parentId`. Admin comments list supports `q` and returns `reports[]` (open reports with reason). Moderation returns `{ id, status, deleted, reportsOpen, commentsCount }`; `RESTORE` also undeletes; `HIDE`/`DELETE` resolve open reports, `DISMISS_REPORTS` dismisses them. Replies of a hidden/deleted parent are not shown nor counted.
- Media: list items add `inUse`, `createdAt`, `deletedAt`, `metadata`; `type` = `webp|png|jpeg|gif` or a full mime; `pageSize` (default 24). Usage items add `slug, status`. `DELETE` in use → 409 with `details.usage`. Estimate adds `originalSize`. Multipart is allowed with cookie auth only on these two paths (middleware CSRF rule).
- Sanitizer: links also allow same-site paths (`/…`) and `#anchors` (no `target`/`rel`); `p`/`h1-6` keep `style="text-align"`; `<img>` allowed attrs as specified plus render-time `loading/decoding`; YouTube iframes get `sandbox`, `allow`, `referrerpolicy`. `<img>` must be under `publicUrl("blog/")`; cover fields must be too (400 otherwise).
- Soft delete (`DELETE /admin/blog/posts/:id`) releases the slug: the post is renamed `<slug>--deleted-<last 10 chars of id>` and its `BlogSlugRedirect` rows are removed, so the slug (and old slugs) can be reused.
- Old slug pages use Next `permanentRedirect` → **308** (not 301); the API returns `{ redirectTo }`.
- Stats: `series` = `BlogPostDailyStat` days + unprocessed logs (any day in range, incl. today); `totals.views/visitors` are summed from `series`, so they always agree. `period` in the response; `visitors` totals are sums of daily per-post uniques (a reader of 2 posts counts twice); `byCategory` counts the category the post is linked to (no roll-up to parent).
- Scheduled publishing revalidates `/blog`; admin mutations revalidate the `/blog` layout and sitemap.
